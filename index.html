Architecture

A minimal two-file stack: a Python Flask server handles all data fetching and analysis, and a single vanilla JS page handles all rendering. No React, no Node, no database. The backend exposes a single /api/refresh endpoint that fans out to 120+ concurrent yfinance calls via ThreadPoolExecutor(max_workers=16), aggregates bias signals, sector breakdowns, and news — then returns a single JSON payload. The frontend consumes that payload and renders everything client-side with zero page reloads.

Prompt Engineering for Structured Financial Analysis

Each ticker's driver narrative is generated by a deterministic rule engine that mirrors the structure of a prompt chain. Given price delta, confidence band, and a news headline, the system outputs a single sentence following the pattern: "[arrow] [pct]% — [catalyst] [implication]". This mirrors prompt engineering best practice: a tight output schema enforced not by a language model but by a typed function — ensuring consistent, parseable output at 120× scale without LLM latency or cost.

AI Agent Design

The terminal is designed as an observation-action loop — the core pattern behind AI agents. Each refresh cycle the agent (1) observes the market via yfinance, (2) scores each ticker against a bias policy (a rule set equivalent to a system prompt), (3) ranks opportunities by a weighted scoring function, and (4) surfaces the best signal — exactly what a human analyst would do. The auto-refresh timer closes the loop autonomously.

Ask the Market — Conversational AI Layer

A fixed chat panel invokes Claude claude-sonnet-4-6 with the web_search tool to answer free-text questions about any stock and return a structured JSON verdict — BUY / WAIT / AVOID, confidence score, entry/stop/target levels, and a plain-English explanation. A rule-based fallback runs without an API key so the panel is always functional. The hardest engineering problem was intent parsing: a 4-step priority chain distinguishes an intentional ticker ("LUNR") from identical-looking English ("now", "be", "go") using original-case scanning, a curated STOPWORDS set, an AMBIGUOUS set for tickers that double as common words (NOW, AI, NET), and a price-mismatch guard that catches ticker mis-detections when the fetched price is 10× off from a price the user mentioned. News relevance is enforced with word-boundary regex so "NOW" never matches inside "Snowflake".

Financial Data Visualization

Five distinct visualization layers are rendered in pure JS with no charting library:

  • →Scrolling ticker tape — CSS @keyframes animation, speed scales with ticker count
  • →Sector heat map — avg % change per sector drives RGB interpolation between green and red, intensity proportional to magnitude
  • →SVG risk gauge — arc stroke-dashoffset and needle rotation animated with CSS transitions; composite score from VIX + bear ratio
  • →Donut pie chart — Canvas 2D API, gap between slices, center hole, hover hit-testing via atan2
  • →Bull/bear breadth bar — three-segment flex bar (bull / neutral / bear) with CSS transitions on data update
